# Nubian Kings artwork inventory

Audit date: 29 September 2026

Reviewed all 176 standard database cards (190 artwork variants) and 7 mercenary cards: **197 images total**.

**Printed-stat audit:** all 197 images match the current database. No artwork statistics or database values required correction. Mercenary zeal is printed as X, matching their null zeal / conversion-immunity designation.

**Production packaging:** 59 required images were already bundled. The other 138 images are included in this release. All 138 match their Dropbox originals byte for byte. Of these, 130 were already present in the local working assets but absent from the repository, and eight were restored from Dropbox during this audit.

All image files decode successfully. All referenced variants are included, not just the first image for each card. Archived backup images and deliberately retired cards are excluded from this inventory.
